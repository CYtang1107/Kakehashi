# Shared design system

Mode: Operate. Scope: shared React Native controls, reading settings, representative cards and the older-adult pilot. The user supplied the replacement palette, typography and constraints; no competing aesthetic or image comp is required.

## Direction contract

THESIS: KAKEHASHI feels like a welcoming home where the next useful action is readable and obvious. Existing journeys and choices remain the content.

OWN-WORLD: warm ivory, white cards, sage notes, deep-green actions, charcoal typography, rounded rectangles and restrained offset shadows. Peach is a supporting surface, never low-contrast text.

STORY: read who is coming, understand the door rule, choose help and receive clear feedback; adjust reading without losing the current task.

FIRST VIEWPORT: a compact labelled toolbar, a readable greeting/date, then the upcoming visit and visitor information. Help uses named spacious actions in a second desktop column or the same phone reading sequence. No hero, invented metric or decorative art.

FORM: user-pinned home-companion direction supersedes seed 54940624. App controls stay native-compatible; a stable reading-settings dialog is the signature interaction. The code-led path matches this scoped app task.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
